# Границы студенского модуля Frontend B

- `gateway.ts` — типизированные HTTP-адаптеры существующего OpenAPI через общий API-клиент. Cookie и CSRF остаются в согласованном механизме платформы. Здесь нет React-состояния и подмены ошибок демо-данными.
- `useStudentSession.ts` — временный read-only мост к сессии: один запрос при входе в каркас, фоновая проверка по focus и немедленная перепроверка после события 401. Смена маршрута не перегружает сессию. Поздние ответы игнорируются; ошибка закрывает доступ. Изменение пользователя или прав перемонтирует приватное содержимое. При появлении FE-C AuthProvider источник заменяется его согласованным интерфейсом; отдельного входа, токенов и постоянного хранилища модуль не создаёт.
- `StudentRoot.tsx` — только граница доступа, шапка и навигация. `shared.tsx` — небольшие компоненты отображения. StudentRoot отделён от AppShell, поскольку его текущие области university/mentor/admin не описывают студенческие маршруты. Переиспользованы общие Brand, UI kit, feedback и tokens.css; отдельной дизайн-системы нет. Общий responsive shell можно выделить после согласования навигации областей.
- `hooks.tsx` — состояния загрузки и действий, контекст зависимости. Компоненты страниц отвечают за сценарий и маршрутизацию.
- `dashboardSignals.ts` — небольшие клиентские проекции существующих DTO. Приглашения запрашиваются с `status=PENDING`, счётчик берётся из отфильтрованного server total. Подробности кейсов загружаются максимум для шести уникальных идентификаторов текущей страницы; частичные ошибки не скрывают успешные результаты. Счётчики активных кейсов и черновиков явно относятся к первой странице. Дополнительные агрегатные endpoints не вводятся.
- `profileConflict.ts` — сравнение исходной версии, локального черновика и последней серверной версии. PATCH содержит только изменённые поля и актуальный expectedVersion; очистка института — null. После 409 форма сохраняется. Пользователь отдельно загружает текущую версию, выбирает значения спорных полей, применяет выбор к форме и повторно сохраняет. Автоматического PATCH или перезаписи нет. Изменённые только на сервере поля сохраняются; массивы сравниваются целиком. Повторный 409 снова оставляет черновик.
- `demo.ts` и расширение второго дня `day2Demo.ts` — явные учебные данные в памяти, не fallback для API. В PR #8 действие приглашений обозначено «Скоро», в PR #10 ведёт в общий раздел команд. Общие исправления перенесены линейными коммитами, навигация PR #10 не дублируется.
- `contracts.ts` генерируется из OpenAPI; `python3 scripts/generate_student_types.py --check` проверяет актуальность. Зависимость генератора: `python3 -m pip install -r scripts/requirements-codegen.txt`. Сгенерированный файл вручную не форматируется.

CSS кабинета использует общие токены. Повторные базовые правила шапки, меню и демо-плашки сведены в одно место, устаревшие селекторы удалены; адаптивные правила и стили команд второго дня сохранены.

Ограничения MIME/размера аватара требуют согласованных значений в серверном контракте. Новые значения не вводятся односторонне; существующие операции загрузки и удаления сохранены.

Проверки: приглашение за пределами истории первой страницы; независимые ошибки обзора; ограничение fan-out; восстановление после 409 с явным выбором; защита формы при focus и навигации; закрытие доступа после смены сессии. Браузерные тесты и снимки проверяют 320/360/375/400/1280 px, раскрытое меню и отсутствие горизонтального скролла.
