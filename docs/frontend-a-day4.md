read-only, ошибка сохранения и 409 с сохранением ввода. Обновление после
409 только явное, решения автоматически не повторяются. Для критических
команд mock сохраняет ключ и отпечаток запроса. Двойное подтверждение
блокируется синхронно до завершения операции.

## Как посмотреть

Из frontend выполнить `npm run dev`, открыть `/company/cases`, нажать
«Открыть демонстрацию». Над списком доступны два сценария дня 4:

- `/company/cases/d4000000-0000-4000-8000-000000000001/workspace` — выполнение,
  TEAM N=2, SOLO N=1, совместные призовые места разрешены. Завершить отбор,
  финальный приём, начать оценивание, назначить нескольким командам 1 место.
- `/company/cases/d4000000-0000-4000-8000-000000000002/workspace` — сразу
  оценивание; совместные места запрещены.

Публикация итогов не выполняется. Черновики отзывов и наград остаются
приватной демонстрацией и не изображают работающий backend.
