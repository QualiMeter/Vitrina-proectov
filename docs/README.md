# Документация API «Витрина ИТ-проектов»

**Версия проекта:** `0.1.3-draft` · **Дата:** 29.10.2026 · **Не реализовано в backend**.

## Навигация

- [`api/openapi.yaml`](api/openapi.yaml) — единый HTTP-контракт OpenAPI 3.1 для корпоративного P0-сценария.
- [`api/REQUEST-EXAMPLES.md`](api/REQUEST-EXAMPLES.md) — примеры запросов frontend.
- [`api/REVIEW-CHECKLIST.md`](api/REVIEW-CHECKLIST.md) — проверки перед утверждением.
- [`architecture/cases-teams-applications.md`](architecture/cases-teams-applications.md) — кейсы, команды и заявки.
- [`architecture/execution-submissions-files.md`](architecture/execution-submissions-files.md) — этапы, сдачи, отбор, приватные файлы и NDA.
- [`architecture/case-evaluation-results.md`](architecture/case-evaluation-results.md) — оценивание, отзывы, победители и публикация.
- [`decisions/001-auth-and-permissions.md`](decisions/001-auth-and-permissions.md) — согласованные решения и неутверждённые проектные предположения.
- [`ci-cd.md`](ci-cd.md) — существующая документация CI/frontend.

## Ответственные

- **Backend** — владелец HTTP-контракта и бизнес-валидации.
- **Тимлид** — утверждение бизнес-решений, приоритета и изменения DTO.
- **FE-A/B/C** — потребители одной схемы; не придумывают отдельные HTTP-контракты.
- **DevOps** — согласование конфигурации окружений, файлового хранилища и проверок.

## Статус и ограничения

- Контракт содержит **85 операций, 137 схем**. Это **не** 85 реализованных эндпоинтов.
- Покрыт **основной корпоративный P0-сценарий**: регистрация → компания → кейс → заявка/команда → выполнение/отбор → результаты.
- Вне этой версии: отдельные модели портфолио, студенческих инициатив, закрытых продуктовых проектов, кадрового поиска, полной аналитики, администрирования и уведомлений (P1 по пятидневному плану). Они **не отменяются**, но требуют отдельного расширения единого `openapi.yaml`.
- **Решения к утверждению:** SOLO/BOTH на отборе, личное подтверждение NDA, повторная подача после REJECTED, смена состава и капитана после подачи, шкала/публикация имён, типы файлов, полная матрица прав.
- Полная независимая OpenAPI-валидация и интеграционные тесты настоящего ASP.NET Core пока не выполнены. Пройдены структурные и JSON Schema-проверки локально.

**Правило:** не объединять в `main` как окончательно утверждённый контракт, пока TL и backend не рассмотрят `REVIEW-CHECKLIST.md`. На frontend mock можно работать со статусом **UI Ready**; **Done (API)** — только по реальным интеграционным проверкам.
