# Golos Text

Unmodified WOFF2 subsets from Google Fonts Golos Text v7, used at weights
400, 500, 600 and 700. The original CSS declarations and Unicode ranges
are retained; only URLs point to local files.

Source CSS: https://fonts.googleapis.com/css2?family=Golos+Text:wght@400;500;600;700&display=swap

Upstream: https://github.com/googlefonts/golos-text

License: SIL Open Font License 1.1, included in OFL.txt.

All four original subsets are included: Cyrillic, extended Cyrillic,
Latin and extended Latin. Local hosting prevents external font requests
from delaying page loads, screenshots and document.fonts.ready.
